## 📌 Featured Projects

### 🛣️ ROADIS

**Road Damage Detection & Infrastructure Complaint Mapping System**

A system for detecting and mapping road damage using **YOLOv11 and GIS**, combined with road authority classification to optimize infrastructure complaint routing.

**Tech:** `React` `Go` `Flutter` `YOLOv11` `GIS` `OpenStreetMap`

---

### 🏠 Appkonkos

**Rental Property Search & Booking Platform**

A web and mobile application for finding and booking nearby **kos and rental properties**, designed to simplify the process for both users and property owners.

**Tech:** `Laravel` `Flutter` `MySQL`

---

### 📚 Scrollify

**Digital Comic Reading Platform**

A web application focused on reading **manhwa, manga, and manhua** with a modern and comfortable reading experience.

**Tech:** `React` `Laravel`
